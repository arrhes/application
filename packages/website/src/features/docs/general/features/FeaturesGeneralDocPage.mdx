# Fonctionnalités

Découvrez toutes les fonctionnalités d'Arrhes pour gérer votre comptabilité de manière simple et efficace.

## Saisie des écritures

Enregistrez vos écritures comptables avec une interface intuitive.

- Journal chronologique
- Lettrage automatique

## Espace de stockage

Organisez vos documents et accédez-y rapidement.

- Pièces justificatives (factures, relevés bancaires, etc.)
- Visualisation des documents
- Volume offert de 1 Go par organisation

## Documents comptables

Générez tous vos documents comptables de synthèse conformes aux normes françaises.

- Grand livre, Balance générale, Bilan comptable, Compte de résultat
- Export du Fichier des Écritures Comptable (FEC)
- Mise à jour automatique à chaque nouvelle écriture
- Export PDF

## Multiple organisations

Gérez plusieurs structures avec un seul compte et collaborez en équipe.

- Organisations illimitées
- Gestion des membres
- Exercices illimités

## API REST

Intégrez Arrhes à vos outils grâce à notre API complète.

- Authentification par clé API
- Accès complet aux écritures et documents
- Documentation intégrée

## Assistant IA

Posez vos questions comptables en langage naturel et obtenez des réponses contextuelles.

- 1 million de tokens inclus
- Accès aux écritures et documents de l'organisation
- Questions en langage naturel

## Reconnaissance optique (OCR)

Extrayez le texte de vos documents pour les analyser avec l'assistant IA.

- 100 pages incluses
- Formats PDF, JPEG, PNG
- Intégration directe avec l'assistant IA

## Sécurité

Vos données sont protégées avec les meilleures pratiques de sécurité.

- Chiffrement bout-en-bout
- Sauvegardes automatiques
- Hébergement en France
