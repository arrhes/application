## ExportsCommandsCliDocPage

Génère un Fichier des Écritures Comptables (FEC) pour l'exercice spécifié. La commande retourne une
                    URL signée pour télécharger le fichier.

Génère un fichier XBRL du bilan comptable pour l'exercice spécifié. La commande retourne une URL
                    signée pour télécharger le fichier.

Génère un fichier XBRL du compte de résultat pour l'exercice spécifié. La commande retourne une URL
                    signée pour télécharger le fichier.
